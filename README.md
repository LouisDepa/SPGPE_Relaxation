# 2D Bose Gas Relaxation Simulator (Growth SPGPE)

This repository contains a numerical implementation of the **Simple Growth Stochastic Gross-Pitaevskii Equation (SPGPE)** to model the non-equilibrium dynamics and thermalization of a two-dimensional (2D) Bose gas following a rapid parameter quench.

* To simulate an initial state : Relaxation_launcher.ipynb
* To simulate an ensemble of quench relaxation : Loop_quench.ipynb
* An example of plot for the S(k) relaxation : Plot_loop.ipynb
